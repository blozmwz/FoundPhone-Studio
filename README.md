# 礼拜四 · 前两章试玩

这是玩家自己的手机。房东突然卖房，好友Yuki帮忙牵线，你重新联系到以前的同学Hendery。

[打开试玩](https://blozmwz.github.io/FoundPhone-Studio/)

目前开放重新联系、看房与是否入住。两种选择都能正常结束；入住后的故事仍在打磨，本版不含后续剧情数据和图片。锁屏密码0917，第一次输错会得到提示。
