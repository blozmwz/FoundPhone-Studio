## 本地工作与校验

项目需要 Node.js；当前 GitHub Actions 使用 Node 22。先检查本机版本与项目要求，再决定是否安装工具。

首次安装依赖：`npm ci`。

启动本地预览：`npm run dev`。打开终端实际输出的本地网址；不要假定端口一定为 5173。开发服务器运行时，保存文件后即可在本机预览，通常不需要先提交到 GitHub。

故事变更至少运行 `npm run story:validate`、`npm run story:test`、`npm run build`。代码变更还运行适用的 `npm run typecheck`、`npm run lint`、`npm test`；涉及交互时做相应浏览器检查。不要无意义地反复运行同样的检查。

`main` 的 push 会触发 `.github/workflows/pages.yml` 构建并部署 GitHub Pages。不要把“本地修改完成”“提交到 GitHub”“网站已发布”混为一谈；告知上线成功前核实部署结果。遇到旧页面可能是 PWA 缓存，先重新加载确认。用户明确授权提交/发布后，按其授权范围执行。

保留 MIT、第三方许可证和版权声明；不要提交凭证、私人账号数据、真实私人聊天或未经授权的素材。
